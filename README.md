# دانلود منیجر

رابط کاربری فارسی و واکنش‌گرا با HTML، CSS و JavaScript خالص.

## اجرا
فایل‌ها را در یک پوشه قرار دهید و با یک وب‌سرور محلی اجرا کنید. برای نمونه:

```bash
python -m http.server 8080
```

سپس آدرس `http://localhost:8080` را باز کنید.

## قابلیت‌ها
- افزودن لینک مستقیم HTTP/HTTPS
- نمایش پیشرفت و حجم دریافت‌شده در صورت ارسال Content-Length
- توقف موقت خواندن جریان دانلود و ادامه همان جریان در نشست جاری
- تلاش مجدد، حذف، مرتب‌سازی، جستجو و فیلتر دسته‌بندی
- ذخیره فراداده فهرست در localStorage
- حالت روشن/تاریک و manifest نصب‌پذیری

## محدودیت‌های مهم مرورگر
- لینک باید فایل مستقیم باشد؛ صفحه دانلود، لینک نیازمند ورود و لینک‌های دارای توکن منقضی‌شونده ممکن است کار نکنند.
- سرور مقصد باید CORS را برای دامنه برنامه مجاز کرده باشد؛ در غیر این صورت مرورگر اجازه خواندن فایل را نمی‌دهد.
- دانلود از طریق `fetch` ممکن است کل فایل را در حافظه نگه دارد و برای فایل‌های بسیار بزرگ مناسب نیست.
- توقف/ادامه در این نسخه به معنی مکث جریان دریافت در همان نشست است؛ ادامه از نقطه قبلی پس از بستن صفحه یا قطع شبکه پیاده‌سازی نشده است.
- برای دانلود پایدار فایل‌های بزرگ، چنداتصالی، صف واقعی و ادامه با HTTP Range به بک‌اند اختصاصی نیاز است.
- این پروژه فعلاً PWA پایه (manifest) دارد؛ برای نصب کامل آفلاین باید روی HTTPS میزبانی و service worker اضافه شود.

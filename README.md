# دانلود منیجر ۴.۲ — هادی رسولی

**دانلود آسان، مدیریت هوشمند، همیشه همراه شما**

وب‌اپلیکیشن فارسی، واکنش‌گرا و قابل نصب که برای انتشار مستقیم روی GitHub Pages آماده شده است.

## امکانات
- رابط فارسی و راست‌چین با طراحی سازگار با موبایل، تبلت و دسکتاپ
- پوسته روشن و تاریک با ذخیره انتخاب کاربر
- پنجره معرفی و نصب وب‌اپلیکیشن و راهنمای نصب برای مرورگرهای مختلف
- ثبت لینک‌ها و نگهداری فهرست در IndexedDB مرورگر
- جستجو، مرتب‌سازی و فیلتر وضعیت دانلودها
- شروع دریافت، توقف دریافت جاری، حذف و پاک‌سازی موارد تکمیل‌شده
- نمایش وضعیت و پیشرفت دریافت در صورت اجازه سرور مقصد
- Service Worker برای کش فایل‌های اصلی برنامه و به‌روزرسانی نسخه
- استقرار خودکار از طریق GitHub Actions

## انتشار در GitHub Pages
1. همه فایل‌های این پوشه را در ریشه مخزن GitHub قرار دهید؛ فایل `index.html` باید در ریشه باشد.
2. تغییرات را روی شاخه `main` ثبت کنید.
3. در `Settings → Pages → Build and deployment`، گزینه `GitHub Actions` را انتخاب کنید.
4. از بخش Actions موفقیت اجرای `Deploy static PWA to GitHub Pages` را بررسی کنید.
5. نشانی نمایش‌داده‌شده در بخش Pages را باز کنید.

برای این پروژه نیازی به نصب وابستگی یا اجرای فرمان build نیست.

## نصب وب‌اپلیکیشن
سایت را با HTTPS باز کنید. در مرورگرهای پشتیبانی‌شده، پنجره نصب نمایش داده می‌شود. در iPhone/iPad از منوی Share گزینه Add to Home Screen را انتخاب کنید. نمایش گزینه نصب به پشتیبانی مرورگر و شرایط نصب بستگی دارد.

## محدودیت دریافت فایل
دریافت همراه با نمایش پیشرفت از طریق مرورگر فقط زمانی ممکن است که سرور میزبان فایل، دسترسی CORS را برای سایت مجاز کرده باشد. در صورت محدودیت CORS، از گزینه بازکردن لینک مستقیم استفاده کنید تا مرورگر مقصد دریافت را مدیریت کند. توقف دریافت جاری پشتیبانی می‌شود؛ ادامه از نقطه قبلی و دانلود چنداتصالی در این نسخه ارائه نمی‌شود.

## حریم خصوصی
فهرست لینک‌ها و وضعیت‌ها در IndexedDB همان مرورگر ذخیره می‌شود و به سرور این پروژه ارسال نمی‌شود. پاک‌کردن داده‌های سایت یا تغییر دستگاه/مرورگر می‌تواند این فهرست را حذف یا غیرقابل دسترس کند.
